The screenshots/ folder

TipAdd your own screenshots

Diagrams for each section live in screenshots/ and show up automatically in a Reference diagrams & screenshots panel at the top of that section. To add your own (Swagger UI, Azure Portal, SSMS execution plans, Postman, Visual Studio…):

  1. Save the image as screenshots/NN-your-title.png (or .jpg, .webp, .svg) — NN is the two-digit section number, e.g. 05-ef-core-sql-log.png appears under Entity Framework Core. Use 00- for the home page.
  2. Run build.bat (or python tools/build.py) once to refresh index.html.

The caption is taken from the file name (hyphens become spaces) or from the SVG's <title>.
